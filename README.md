# Glo ERS Web Services API PHP SDK
This package is a SDK for ERS Web Services SOAP API

To install, run the following composer command:
```
composer require meeshalk/glo-api-php-sdk
```

To Config:
edit the config file `config/soap-client.php` according to your SOAP Engine

For custom or new classes: 
Submit issue or pull request, this package useage [`phpro/soap-client`](https://github.com/phpro/soap-client) as Soap Client.
